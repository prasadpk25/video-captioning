# Video Captioning

Automated video captioning system that extracts visual features from video frames
and generates natural language descriptions.

## What it does
- Extracts frame-level visual features from video
- Generates natural language captions using sequence modeling
- End-to-end pipeline from raw video to text output

## Tech Stack
- Python · Computer Vision · NLP · Jupyter

## How to Run
1. Open the notebook in Jupyter or Google Colab
2. Run all cells in order
